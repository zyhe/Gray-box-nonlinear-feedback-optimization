## Gray-box nonlinear feedback optimization

This repository contains code for *Gray-Box Nonlinear Feedback Optimization* published in IEEE Transactions on Automatic Control, Oct. 2026 [(pdf)](https://doi.org/10.1109/TAC.2026.3693174) [(full text)](https://arxiv.org/pdf/2404.04355).

Authors: [Zhiyu He](http://zyhe.github.io/), [Saverio Bolognani](https://www.bsaver.io/), [Michael Muehlebach](https://sites.google.com/view/mmuehlebach/), [Florian Dörfler](https://dorfler.ethz.ch/).

## Main contents
`experiment` (static unconstrained problem) <br>

`experimentTracking` (time-varying constrained problem) <br>

Please see the README.md file of each folder for more details.
